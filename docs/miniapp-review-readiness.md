# 微信小程序提审准备清单

## 本次代码改造范围

- 首页从单一设备编号查询改为完整服务入口。
- 保留原有微信登录、设备绑定和真实设备 API，不改变生产数据流程。
- 增加无需设备的匿名只读演示模式，覆盖概览、健康趋势、位置记录和安全事件。
- 增加使用说明、隐私与数据说明、医疗与救援免责声明。
- 增加接口失败后的页面级错误提示和重试入口。
- 将“实时监测”“跌倒警报”等容易形成过度承诺的表述调整为“设备数据同步”“疑似跌倒事件”。

## 建议审核体验路径

1. 打开小程序首页。
2. 点击“体验匿名示例”。
3. 在守护中心依次进入“健康趋势”“位置记录”“安全事件”。
4. 确认每页均标识“匿名示例 · 只读体验”，且不要求绑定设备。
5. 返回首页，打开“使用说明”和“隐私说明”。

## 已记录、未在本次修改的事项

这些事项涉及后端数据模型、设备协议或运营决策，为避免改变关键功能，本次仅记录：

1. **云端解除绑定与数据删除**：当前只有本机“最近查看”清除能力，尚无用户自助解除设备绑定或删除云端数据的 API。正式面向公众前建议补充。
2. **运营主体联系方式**：代码仓库没有可确认的客服邮箱或电话，需要运营者在微信后台隐私保护指引中填写真实有效信息。
3. **服务类目与资质**：需根据小程序主体类型和实际经营范围在微信公众平台确认，代码无法代替后台选择。
4. **设备告警类型**：设备 `AL` 报文可能包含围栏等不同状态，目前后端仍按现有逻辑生成疑似跌倒事件，需结合设备协议另行确认和修正。
5. **历史异常时间**：生产库中已定位到少量历史 2036 年异常记录；新数据已具备异常时间过滤，但历史数据修正需单独确认生产数据变更。
6. **健康数据边界**：页面已增加日常照护免责声明，但运营文案、类目和宣传材料也应避免医疗诊断、疗效或救援保证类表述。
